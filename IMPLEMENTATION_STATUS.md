# Статус приёмки v1.0.0

Проверка на Windows 11 x64. Итоги относятся к проверенной машине, сети и бинарникам; не являются обещанием одинаковой доступности у всех пользователей.

| Проверка | Подтверждённый результат |
|---|---|
| Сборка и автоматические тесты | 105 тестов; парсер, ресурсы, цели, очередь, изоляция, достоверность, скоринг и сортировка |
| Flowseal 1.10.3 | 22 исходных профиля, новый формат GameFilter; сохранена поддержка 1.10.2 |
| Нативные фильтры | 22 исходных и 22 LoL-варианта, 17 600 случаев для TCP/UDP, IPv4/IPv6 и направлений |
| Живая изоляция 1.10.3 | Основной процесс и два кандидата; блокировка только A не мешает B и основному потоку; восстановление A и трассировка |
| Общая серия 1.10.3 | 66/66 завершённых достоверных результатов, 44 запуска, пик 4 процесса / 8 запросов, 152,4 с |
| Серия и достоверность | Переключение вкладок, предварительные результаты, отмена, конфликт WinDivert, независимость результатов сервисов |
| WPF | 22 карточки; рендеры 100/200%, ширины 1150/1390 DIP; 352 подсказки, клавиатура, выбор и сортировка |
| Сохранность | Исходные файлы Flowseal неизменны; временные процессы убраны; исходный режим возвращён |

66/66 означает завершение измерений, а не 66 успешных подключений. Ошибки и предупреждения серверов сохраняются как результаты.

В предыдущей приёмке 1.10.2 проверялись переход со службы, восстановление, отказ смены основной стратегии, потеря GUI, падение Helper и общего процесса Discord/YouTube. В повторной приёмке 1.10.3 эти аварии и первый запуск драйвера с нуля отдельно не повторялись; существующей службы на машине уже не было. Подробности: [COMPATIBILITY-1.10.3.md](docs/COMPATIBILITY-1.10.3.md).

Авторизованные клиенты, Discord WebSocket/голос, игровой матч и воспроизведение видео не проверяются. Полный ручной обход всех диалогов, перезагрузка Windows, другие компьютеры и живой IPv6/UDP-медиасеанс не входят в подтверждённые результаты. Масштабы проверялись WPF-рендером, без переключения системного DPI.

Контрольные суммы движка остаются закреплёнными в `isolation-certificate.json`. Переименование каталога или ручное изменение сертификата не заменяет эксперимента с другим движком.
