Zapret Tester — инструкция пользователя

Для Windows 11 x64 · инструкция к версии 1.0.0 · 28 сентября 2026 года

Zapret Tester помогает сравнить стратегии Flowseal для Discord, League of Legends и YouTube, а затем вручную включить выбранную стратегию. Стратегия — это вариант настроек обхода; в программе они называются General, ALT, ALT2 и так далее.

Знания кода не нужны. Для обычного использования не требуется терминал, сборка проекта, установка Python или SDK .NET. Готовая переносимая версия содержит среду запуска. Папки, регион игры и параметры проверки выбираются в окнах программы.

Первый запуск выглядит так: скачать два архива → распаковать → открыть Zapret Tester → выбрать папку Flowseal → проверить → сделать подходящую стратегию основной. При запуске сетевого помощника Windows запросит права администратора.

1. Что понадобится

Что Для чего
Windows 11 x64 Поддерживаемая платформа этой сборки. Работа на других системах не подтверждена.
Готовый архив Zapret Tester для Windows x64 Само приложение. Нужен архив программы, а не архив исходного кода.
Совместимая сборка Flowseal 1.10.2 или 1.10.3 Программа читает её стратегии и использует её сетевой движок.
Возможность подтвердить запрос администратора Windows Нужна для сетевого помощника и управления основным Zapret.
Установленная League of Legends Нужна только для проверок LoL: из игры читаются адреса служб и список регионов.

Проверены Flowseal 1.10.2 и 1.10.3. Для 1.10.3 выполнены проверка всех 22 профилей и LoL-вариантов, живой эксперимент изоляции и общая серия Discord / LoL / YouTube (66 завершённых проверок сервисов). В актуальном тестере исправлено чтение нового формата GameFilter 1.10.3 (mode/tcp/udp и пользовательские диапазоны портов). Произвольная более новая или изменённая сборка может быть отклонена. Сам номер папки не доказывает совместимость: приложение проверяет содержимое файлов движка.

Flowseal скачивается отдельно с официальных страниц 1.10.2 или 1.10.3. На странице релиза откройте Assets и выберите архив готовой сборки. Сам Zapret Tester не скачивает Flowseal автоматически.

Если LoL не установлена, Discord и YouTube можно проверять отдельно. На дашборде снимите галочку LoL, чтобы отсутствующая конфигурация игры не мешала общей оценке выбранных сервисов.

2. Первый запуск по шагам

Шаг 1. Распакуйте приложение и Flowseal

Распакуйте весь архив Zapret Tester в отдельную папку. Не запускайте программу внутри архиватора и не переносите один EXE без остальных файлов.

Распакуйте Flowseal в другую папку. Например:

Документы
├── ZapretTester
│   ├── ZapretTester.exe
│   ├── ZapretTester.Helper.exe
│   └── остальные файлы приложения
└── Flowseal-1.10.2
    ├── general.bat
    ├── general (ALT).bat
    ├── bin
    └── lists

Названия и расположение папок могут быть другими. Запускать BAT-файлы Flowseal для настройки тестера не требуется.

Шаг 2. Откройте Zapret Tester

Дважды нажмите ZapretTester.exe. Helper отдельно запускать не нужно: приложение запускает его само при необходимости.

Шаг 3. Выберите папку Flowseal

На вкладке Discord нажмите «Выбрать папку…» и укажите папку, в которой одновременно находятся general.bat, bin и lists.

Выбирайте корень распакованной сборки, а не папку bin, не архив и не отдельный BAT-файл. В исследованных сборках 1.10.2 и 1.10.3 появятся 22 стратегии. Папка сохраняется для следующих запусков.

Шаг 4. Если Zapret уже работает

Если вы запускали его вручную через BAT, закройте именно то окно Zapret, которое запускали. Не запускайте несколько копий обхода одновременно с тестированием.

Если Flowseal установлен как служба, перед проверкой передайте управление приложению:

  1. На вкладке Discord выберите свою текущую стратегию. Если не знаете её, можно выбрать General как временный вариант для начала работы.
  2. Нажмите «Сделать основным».
  3. Подтвердите запрос Windows и прочитайте подтверждение перехода.
  4. Подтвердите запуск. Программа сохранит состояние исходной службы, остановит её и отключит её автозапуск; основной Zapret будет запускаться через тестер.

На время перехода возможен краткий перерыв соединения. При ошибке запуска программа пытается восстановить прежнее состояние. Если служба относится к другой папке Flowseal, укажите её фактическую папку либо сначала верните управление через программу, которой она была установлена.

Если другой Zapret не запущен, этот предварительный шаг можно пропустить и сначала выполнить проверки. Основную стратегию вы включите после сравнения результатов.

Шаг 5. Выберите, что проверять

Откройте «Дашборд». Вверху оставьте галочки нужных сервисов: Discord, LoL, YouTube.

Если нужна LoL, сначала проверьте папку игры и регион в Настройках — см. раздел 6. Если она вам не нужна, снимите галочку LoL.

По умолчанию выбраны все стратегии. Кнопка «Выбрать всё» возвращает полный выбор, «Снять выбор» снимает его. Для проверки нескольких вариантов отметьте галочки возле их названий.

Шаг 6. Запустите проверку

Нажмите «Проверить все соединения». Если Windows спросит разрешение для сетевого помощника, подтвердите его. Без этого просмотра старых результатов достаточно, но новые сетевые проверки не запустятся.

Дождитесь завершения серии. Счётчик вида 18/66 проверок сервисов показывает прогресс: для 22 стратегий и трёх сервисов запланировано 66 результатов сервисов. Скорость зависит от сети и числа неудачных попыток.

Пока серия выполняется, оценки её участников остаются нейтральными: программа ещё проверяет достоверность итогов. Это ожидаемое поведение.

Шаг 7. Включите подходящий результат

Оставьте порядок «Лучшие сверху», выберите подходящую стратегию и выполните действия из следующего раздела. Сам тест и сортировка не включают лучшую стратегию автоматически.

3. Как выбрать и включить рабочую стратегию

Сначала смотрите на доступность нужных сервисов и отдельные индикаторы, затем на миллисекунды. Для начала выбирайте вариант с 10 / 10 по вашим выбранным сервисам. Если таких несколько, можно попробовать вариант с меньшей задержкой нужного сервиса.

  1. Запомните название стратегии, например ALT9.
  2. Перейдите на вкладку Discord, YouTube или League of Legends.
  3. Выделите строку с этим названием.
  4. Нажмите «Сделать основным» внизу справа.
  5. Проверьте название в подтверждении и согласитесь.
  6. Откройте нужный сайт или приложение и проверьте свой обычный сценарий.

На какой вкладке применять стратегию:

Вкладка Что будет запущено
Discord или YouTube Исходный вариант выбранной стратегии Flowseal.
League of Legends Вариант этой стратегии с дополнительными настройками для служб LoL выбранного региона и сохранёнными исходными группами.

В программе работает одна основная стратегия. Переключение вкладок её не меняет. Чтобы заменить её, снова выберите строку и нажмите «Сделать основным»; при неудачной смене предусмотрен откат к предыдущему варианту.

Три хорошие оценки на одной карточке не означают, что все три сервиса были проверены через один и тот же LoL-вариант. Discord и YouTube проверяются через исходный вариант, LoL — через адаптированный. Если применяете вариант LoL для повседневного использования, отдельно проверьте привычную работу Discord и YouTube после включения.

4. Вкладки и кнопки

Discord, League of Legends и YouTube

На каждой вкладке находится таблица стратегий: четыре индикатора служб, общий статус, медианная задержка и время проверки. Выберите строку, чтобы увидеть подробности внизу окна; наведите указатель на индикатор для пояснения.

Кнопка Действие
Проверить всё Проверяет все найденные стратегии только для открытого сервиса.
Проверить выбранную Проверяет одну выделенную строку для открытого сервиса.
Остановить проверку Отменяет текущую серию независимо от открытой вкладки.
Обновить Перечитывает профили и сохранённые результаты; сетевую проверку не запускает.
Настройки Открывает параметры проверок, папку и регион LoL.
Диагностика Показывает техническое состояние; при необходимости подключает Helper и запрашивает права Windows.
Журнал Открывает папку журналов для разбора ошибок.
Сделать основным Включает выбранную стратегию для обычной работы.
Остановить основной Выключает основной Zapret, запущенный тестером. Исходную службу Flowseal эта команда не восстанавливает.
Восстановить Flowseal Возвращает сохранённую конфигурацию прежней службы, если она была передана под управление тестера.

Дашборд

Каждая карточка соответствует одной стратегии. Внутри находятся секции выбранных сервисов: логотип, статус, миллисекунды и четыре индикатора. Число в правом верхнем углу — средний балл выбранных сервисов.

Иллюстрация показывает результаты конкретного компьютера и подключения. На другом провайдере или после изменения сети результаты могут отличаться.

Галочки Discord / LoL / YouTube меняют и вид карточек, и состав следующей общей проверки. Галочка рядом с названием стратегии определяет её участие в следующем запуске.

Порядок «Лучшие сверху» сортирует по баллам, а «По названию» возвращает естественный порядок стратегий. При равенстве баллов сохраняется естественный порядок; миллисекунды не используются для автоматического ранжирования. Карточки без оценки находятся в конце рейтинга. Сортировка ничего не скрывает и не меняет выбор стратегий.

Значки на панели дашборда: круговая стрелка — обновить сводку, шестерёнка — настройки, квадрат — остановить серию. Подсказка появляется при наведении. Просмотр карточки или её подсказки ничего не запускает.

Во время проверки можно менять вкладки и галочки. Текущая серия продолжится по составу, выбранному при запуске; изменения относятся к следующей серии. Второй одновременный запуск недоступен. Автоматическая перестановка карточек выполняется после завершения серии; явное изменение сервисов или порядка применяется сразу.

5. Баллы, цвета и миллисекунды

Как считаются баллы

За каждую успешную проверку из четырёх сервис получает 2,5 балла:

Успешных проверок Балл сервиса
0 из 4 0
1 из 4 2,5
2 из 4 5
3 из 4 7,5
4 из 4 10

Ошибки и предупреждения сервера не добавляют баллов. Балл карточки — среднее выбранных сервисов с одинаковым весом. Например: Discord 10 + LoL 10 + YouTube 0 → 6,7 / 10. Если снять галочку YouTube, среднее оставшихся двух сервисов будет 10.

Подсказка оценки показывает баллы каждого сервиса и формулу. Для отображения результат округляется до одного знака после запятой; сортировка и цвет используют точное среднее.

Цвет внешней рамки

Балл Рамка
Менее 5 Красная
От 5 до менее 8 Янтарная
От 8 до 10 Зелёная
Нет подтверждённого среднего Серая

Зелёная рамка означает высокий средний балл. Внутри такой карточки всё ещё может быть отдельная ошибка — смотрите на индикаторы. Все проверки выбранных сервисов успешны только при 10 / 10.

Значки сервиса

Значок Значение
Зелёная галочка Все четыре проверки успешны, результат актуален и достоверен.
Янтарное предупреждение Часть проверок успешна или получено предупреждение сервера.
Красный крест Все четыре проверки завершились ошибкой.
Серый вопросительный знак Проверка ещё не выполнялась.
Серые часы Результат устарел либо серия ещё выполняется; точное состояние — в подсказке.
Серое предупреждение или другой нейтральный значок Результат не подтверждён, конфигурация недоступна, профиль не поддерживается, проверка отменена или заблокирована. Смотрите подсказку.

Если хотя бы один выбранный сервис не имеет полного актуального достоверного результата, общая оценка — «—», рамка серая. Это не ноль баллов и не доказательство плохого соединения.

Что означает «142 мс»

Это медиана времени успешных HTTPS-проверок, без времени поиска адреса DNS. При частичном успехе учитываются только успешные проверки; число успешных адресов видно в подсказке.

Это не игровой пинг, не задержка голоса и не скорость скачивания видео. Задержка не влияет на баллы. При отсутствии успешных измерений или при нейтральном состоянии показано «—».

6. Настройка League of Legends

  1. Откройте Настройки.
  2. Проверьте поле «Папка League of Legends». Установка определяется автоматически, если сведения Riot доступны.
  3. Если папка не найдена, нажмите «…» и выберите папку самой игры, в которой лежит system.yaml. Папка Riot Client сама по себе не подходит.
  4. Выберите свой регион из списка «Регион League of Legends». Доступные регионы берутся из установленной игры; первоначальный выбор читается из её настроек, при отсутствии записи используется RU.
  5. Нажмите «Сохранить» и запустите проверку LoL.

Пароль, вход в аккаунт и токены для проверки не требуются. Программа не меняет файлы Riot. Смена региона выбирает отдельные результаты LoL и не портит результаты Discord или YouTube. Для нового региона нужна своя проверка.

Если игра отсутствует или её конфигурация не читается, LoL останется без оценки. Другие сервисы можно продолжать проверять. На общей карточке средний балл появится после успешного получения результатов LoL либо после снятия её галочки.

7. Настройки программы

Для начала оставьте значения по умолчанию. Эти параметры доступны в окне Настройки; редактировать файлы вручную не требуется.

Поле в окне По умолчанию Что меняет
Параллельных профилей 4 Число одновременно работающих тестовых процессов. Окно допускает от 1 до 5.
Попыток на endpoint 2 Максимум попыток для одного адреса при ошибке. Успешная попытка не повторяется. Диапазон 1–5.
Таймаут попытки, секунд 5 Сколько ждать одну попытку, включая DNS. Диапазон 1–60 секунд.
Начало / конец тестового пула 41000 / 41999 Локальные порты для отделения тестовых соединений. Обычно менять не нужно.
Папка и регион League of Legends Автоопределение, если возможно Какая установка и регион используются для LoL.
Проверять при запуске Выключено Автоматически проверяет открытый сервис при старте программы, а не все выбранные сервисы дашборда. Для первых запусков удобнее оставить выключенным.
Оставлять основной Zapret после закрытия Включено Основная стратегия продолжает работать после закрытия окна.

Изменяйте параметры между сериями. При большом числе попыток может не хватить диапазона портов: например, полный прогон 22 стратегий и трёх сервисов с двумя попытками использует до 528 портов, а с пятью — до 1320, больше стандартного пула. Уменьшите число попыток или объём выбранной проверки; снижение параллельности не уменьшает суммарный расход портов за серию.

Для изменения диапазона портов сначала нажмите «Остановить основной», сохраните настройки и снова примените основную стратегию. Сами адреса проверок и формула баллов в текущем интерфейсе не редактируются.

8. Повседневное использование

  • После настройки: пользуйтесь выбранной основной стратегией; постоянно прогонять все тесты не требуется.
  • Если соединение перестало работать: проверьте нужные сервисы повторно и вручную примените подходящий вариант.
  • После закрытия окна: основной Zapret по умолчанию продолжает работать. Незавершённая тестовая серия отменяется. Если отключить соответствующую настройку, при закрытии окна основной процесс тоже останавливается.
  • После перезагрузки Windows: откройте ZapretTester.exe. При сохранённом управляемом режиме обычный запуск попытается возобновить основную стратегию; Windows может снова запросить разрешение. Автозапуск вместе с Windows эта версия не создаёт.
  • Чтобы выключить обход: откройте одну из вкладок сервисов и нажмите «Остановить основной».
  • Чтобы вернуться к прежнему Flowseal: нажмите «Восстановить Flowseal» и подтвердите возврат сохранённой службы. Это применимо, если она существовала до перехода.

Сохранённые результаты не имеют срока годности по времени. Они устаревают при изменении профиля, его ресурсов или конфигурации проверок. При этом условия у провайдера могут измениться без изменения файлов: старый высокий балл не заменяет новую проверку, если доступность изменилась.

Надпись «Не подключён» при просмотре сохранённого дашборда означает отсутствие связи с Helper, а не отсутствие интернета. Просмотр результатов не требует его запуска. Специальный запуск сразу в дашборд (--dashboard) также не включает основной процесс автоматически; для обычного возобновления используйте запуск EXE без этого параметра.

9. Что именно проверяется

Тестер проверяет доступность четырёх HTTPS-адресов для каждого сервиса. Применяются IPv4, HTTP/1.1 и штатная проверка сертификата TLS. Автоматическое следование перенаправлениям и системный HTTP-прокси для этих запросов отключены.

Сервис Четыре индикатора Что не проверяется
Discord Website, Gateway HTTPS, CDN, Update Авторизация аккаунта, голос и соединение WebSocket.
League of Legends Авторизация Riot, конфигурация клиента, платформа региона, CDN обновлений Вход в аккаунт, подключение к матчу, игровой пинг, голос и Vanguard.
YouTube Сайт, короткие ссылки, изображения, перенаправление видео Воспроизведение, качество и скорость видео.

Для LoL «Авторизация Riot» означает доступность публичной службы авторизации, а не попытку войти в аккаунт.

HTTP 401/403/404/405 иногда допустимы для технических корней: сервер ответил, но корневая страница не предназначена для обычного просмотра. Для авторизации и конфигурации LoL нужен 200; для сайта YouTube и коротких ссылок нужны 2xx/3xx. HTTP 429/5xx всегда отображаются как предупреждения сервера и баллов не дают. Фактический код доступен в подсказке.

Если программа обнаруживает другой обработчик, способный вмешаться в проверку, она блокирует или отменяет серию. Это защита от результатов, ошибочно приписанных не той стратегии. Уменьшение параллельности такую проблему не устраняет.

10. Если что-то не работает

Что видно Что сделать
Пустая таблица, «No supported profiles» Убедитесь, что выбрана папка с general.bat, bin и lists. Проверьте полную распаковку совместимой сборки, затем нажмите «Обновить».
Кнопка общей проверки неактивна Выберите хотя бы один сервис и одну стратегию. Дождитесь завершения текущей серии или остановите её.
Запрос прав Windows отменён Повторите запуск проверки и подтвердите запрос. Если права администратора недоступны, попросите владельца компьютера помочь.
«Engine differs from the validated bundle» Движок отличается от проверенной сборки. Используйте совместимую Flowseal 1.10.2/1.10.3 либо версию тестера с поддержкой вашего движка. Переименование папки и редактирование файла проверки совместимости проблему не решают.
«Отменено» Запустите проверку заново и дождитесь завершения. Если сами не останавливали её, прочитайте сообщение внизу окна и журнал: возможна потеря Helper или конфликт. Это не оценка доступности.
«Заблокировано», сообщение о постороннем WinDivert Закройте известную вам отдельно запущенную копию обхода. Если работает исходная служба Flowseal, передайте её под управление тестера через «Сделать основным». Не завершайте незнакомые процессы по случайному номеру.
WinDivertOpen(layer=4) / «указанная служба не установлена» Убедитесь, что используется актуальный полный архив тестера: в текущей версии предусмотрен первый запуск драйвера. Перезагрузите компьютер и повторите с подтверждением UAC. Если ошибка остаётся, сохраните её полный текст и журнал.
«Could not connect to the pipe because it was not owned by the current user», устаревший Helper или ошибка соединения Не смешивайте файлы разных выпусков. Распакуйте полный актуальный архив, перезагрузите Windows и запустите новую копию. Это завершит оставшийся Helper старого запуска.
LoL без результатов, «Укажите папку League of Legends» или ошибка system.yaml В настройках выберите папку самой игры с system.yaml и корректный регион. Если игра не нужна, снимите её галочку в дашборде.
«Unsupported profile» / «Адаптация не поддерживается» Файл стратегии содержит неподдерживаемые конструкции либо её LoL-вариант нельзя однозначно подготовить. Попробуйте поддерживаемый профиль и приложите название проблемного профиля к сообщению об ошибке.
Не хватает портов / «insufficient port pool» Верните две попытки и стандартный диапазон 41000–41999 либо уменьшите число выбранных стратегий/сервисов. Часть портов может быть занята другими программами; повторите позже.
HTTP 429 или 5xx Сервер ограничил запросы или вернул ошибку. Повторите позже. Это не доказательство неисправности самого Zapret.
Ошибка DNS, TLS или таймаут Проверьте обычное интернет-соединение и дату/время Windows, затем повторите. При таймаутах можно увеличить время ожидания в настройках. Проверку сертификатов отключать не требуется.
Высокий балл, но голос, матч или видео не работают Эти действия не входят в HTTPS-проверку. Убедитесь, что нужная стратегия действительно сделана основной, и проверьте другой вариант в самом приложении или игре.
Общий балл «—», хотя один сервис зелёный У другого выбранного сервиса нет подходящего результата. Проверьте его либо снимите его галочку. Наведите указатель на оценку для причины.
«No saved external service configuration» при восстановлении Сохранённой исходной службы нет. Если её изначально не было, используйте «Остановить основной». Восстанавливать в таком случае нечего.
Windows или защитное ПО не позволяет запустить файл Проверьте источник архива и полный текст сообщения. Не отключайте защиту целиком ради запуска; если файл отсутствует после распаковки, проверьте журнал защиты и обратитесь за помощью.

Если проблема повторяется, укажите версию Windows, версию Flowseal, сервис и регион, название стратегии, полный текст ошибки и действие, после которого она появилась. Кнопки «Диагностика» и «Журнал» находятся на вкладках сервисов. Не публикуйте целиком папку настроек или session.json: для обращения обычно достаточно конкретного сообщения и относящегося к нему фрагмента журнала.

11. Обновление, перенос и удаление

Обновить Zapret Tester

  1. Завершите или остановите проверки.
  2. Скачайте полный архив нового выпуска и распакуйте его в новую папку.
  3. Закройте старое окно и перезагрузите Windows, чтобы старый Helper не оставался в памяти.
  4. Запустите EXE из новой папки. На том же компьютере и под тем же пользователем сохранённые настройки и результаты будут прочитаны из общей папки данных.
  5. Проверьте путь к Flowseal. Если он изменился, выберите фактическую папку на вкладке сервиса; при активном управляемом режиме приложение сначала попросит восстановить исходный Flowseal.

Архив обновляйте целиком: EXE, Helper и сопутствующие файлы должны относиться к одному выпуску. Перед обновлением самого Flowseal проверяйте совместимость с тестером. Результаты после изменения его файлов могут стать устаревшими.

Перенести на другой компьютер

Скопируйте полный архив приложения и подготовьте совместимую Flowseal. На новом компьютере выберите местные папки и заново проведите проверки. Рейтинг зависит от сети; переносить прежние баллы как подтверждение работоспособности не следует. Рабочие настройки пользователя не находятся внутри переносимой папки программы.

Удалить приложение

Сначала остановите проверки. Если хотите вернуться к прежней службе, используйте «Восстановить Flowseal»; если нужно просто выключить основной процесс, используйте «Остановить основной». После этого закройте окно, перезагрузите Windows и удалите папку приложения.

Данные пользователя сохраняются отдельно. Не удаляйте сведения о прежней службе до её восстановления. Если исходной службы не было, действие «Восстановить Flowseal» не требуется.

12. Какие файлы сохраняет программа

Для использования программы эти файлы редактировать не нужно. Таблица нужна для резервной копии и диагностики.

Где Что хранится
Папка распакованного приложения EXE, Helper, библиотеки и данные совместимости.
%LOCALAPPDATA%\ZapretTester\settings.json Папки, регион, параметры проверок и основная стратегия.
%LOCALAPPDATA%\ZapretTester\dashboard.json Выбранные сервисы и стратегии, порядок карточек.
%LOCALAPPDATA%\ZapretTester\results.json Последние результаты отдельно для сервисов, регионов и стратегий.
%LOCALAPPDATA%\ZapretTester\logs Журналы работы.
%PROGRAMDATA%\ZapretTester Защищённые рабочие копии ресурсов и сведения для восстановления исходной службы.

Чтобы открыть пользовательскую папку данных, нажмите Win + R, вставьте %LOCALAPPDATA%\ZapretTester и нажмите Enter. Это открытие папки, а не команда программирования.

Исходные BAT-файлы, списки Flowseal и файлы Riot тестер не изменяет. Для проверок и LoL-вариантов он создаёт рабочие копии. При включении управляемого режима меняется состояние службы Flowseal, как описано в подтверждении.

13. Ответы на частые вопросы

Можно всё настроить мышкой? Да: выбрать папку Flowseal, папку и регион LoL, сервисы, стратегии, параметры проверки и основной вариант. Терминал и правка кода для обычного использования не нужны.

Нужно выбирать всё заново при каждом запуске? Нет. Пути, настройки, выбранные сервисы, стратегии и порядок сохраняются. После перезагрузки Windows нужно снова открыть программу, чтобы возобновить управляемый основной Zapret.

Достаточно скачать только Zapret Tester? Нет. Нужна отдельная совместимая сборка Flowseal; для LoL также нужна установленная игра. Движок и стратегии Flowseal в архив тестера не входят.

После теста программа сама включит победителя? Нет. Нажмите «Сделать основным» на нужной вкладке. Рейтинг помогает выбрать, но автоматического переключения нет.

Можно проверить только Discord? Да. Нажмите «Проверить всё» на вкладке Discord либо оставьте только Discord в дашборде.

Можно пользоваться интернетом во время серии? Да, основной Zapret управляется отдельно. Однако посторонняя копия обхода может вмешаться и привести к блокировке серии. Во время сравнения не запускайте дополнительные экземпляры Zapret.

Что означает 10 / 10? Все HTTPS-проверки выбранных сервисов прошли успешно при подтверждённой изоляции. Это не гарантия всех функций приложения или постоянной доступности в будущем.

Почему два человека видят разные лучшие стратегии? Результаты зависят от провайдера, маршрута, сети, региона и состояния серверов. Выбирайте по проверке на своём подключении.

Почему недостаточно просто выбрать папку, чтобы всё заработало? Выбор папки загружает стратегии. Затем нужно запустить сравнение и явно включить подходящую стратегию. Все эти действия доступны кнопками в приложении.
