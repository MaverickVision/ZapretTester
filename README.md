# Zapret Tester

**Найдите подходящую стратегию Flowseal для Discord, League of Legends и YouTube — без ручного перебора BAT-файлов.**

Приложение для Windows 11 x64 проверяет HTTPS-службы через каждую стратегию, показывает доступность и задержку, а на дашборде сортирует результаты по баллам от 0 до 10. Выбор основной стратегии остаётся за вами.

**[Скачать готовую программу](https://github.com/mwell8/ZapretTester/releases/latest)** · [Полная инструкция](docs/USER_GUIDE.ru.md) · [Сообщить об ошибке](https://github.com/mwell8/ZapretTester/issues)

## Быстрый старт

1. На странице **Releases** скачайте `ZapretTester-win-x64.zip` из раздела **Assets**. Архивы **Source code** предназначены для разработчиков.
2. Распакуйте весь архив в отдельную папку. Устанавливать .NET, Python или средства разработки не требуется.
3. Отдельно скачайте и распакуйте совместимую [Flowseal 1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3) или [1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2).
4. Запустите `ZapretTester.exe`, нажмите **Выбрать папку** и укажите корень Flowseal: рядом должны быть `general*.bat`, `bin` и `lists`.
5. Если Flowseal уже работает как служба, на вкладке сервиса выберите текущую стратегию и нажмите **Сделать основным**. Подтвердите переход под управление тестера и запрос администратора Windows. Неизвестные активные обработчики WinDivert блокируют проверку.
6. Откройте **Дашборд**, выберите сервисы и стратегии, затем нажмите **Проверить все соединения**. Без установленной LoL снимите галочку **LoL**. Для начала проверки Windows может запросить разрешение Helper.
7. Сравните результаты. Чтобы включить подходящий вариант, выберите его на вкладке нужного сервиса и нажмите **Сделать основным**.

Все основные настройки доступны в интерфейсе. В архиве есть **ИНСТРУКЦИЯ.html**: откройте её двойным щелчком для подробного руководства без интернета.

## Возможности

- Отдельные вкладки **Discord**, **League of Legends**, **YouTube** и общий **Дашборд**.
- Четыре HTTPS-индикатора на сервис: доступность, фактический HTTP-код, причина ошибки и время проверки.
- Медиана времени успешных HTTPS-запросов в миллисекундах; DNS измеряется отдельно.
- Выбор сервисов и стратегий, общий прогон и отдельная проверка выбранной стратегии.
- Баллы доступности, цветная обводка карточек и порядок **Лучшие сверху / По названию**.
- Региональные LoL-варианты стратегий на основе установленной игры, включая RU.
- Сохранение результатов и настроек; просмотр дашборда сам не запускает сетевые проверки или Helper.
- Управление основной стратегией, остановка проверки и возврат к исходной службе Flowseal.

## Что означают баллы и цвета

Каждая успешная проверка одной из четырёх служб даёт сервису **2,5 балла**. Оценка карточки — среднее выбранных сервисов с одинаковым весом: `10 + 10 + 0 → 6,7 / 10`.

| Обводка | Оценка |
|---|---|
| Зелёная | От 8 до 10 |
| Янтарная | От 5 до менее 8 |
| Красная | Менее 5 |
| Серая | Оценка недоступна |

Если хотя бы у одного выбранного сервиса нет полного актуального достоверного результата, общая оценка — `—`. Устаревшие, выполняющиеся, отменённые и заблокированные проверки не означают недоступность сервиса. Предварительные результаты серии не получают окончательный зелёный статус до проверки её достоверности.

**Баллы оценивают долю доступных HTTPS-служб. Они не оценивают скорость интернета или качество обхода во всех сценариях.** Миллисекунды — время HTTPS-проверок, а не игровой ping.

## Что проверяется

| Сервис | Четыре проверки | Что не проверяется |
|---|---|---|
| Discord | Сайт, Gateway HTTPS, CDN, Update | Вход в аккаунт, WebSocket и голос |
| League of Legends | Авторизация Riot, конфигурация клиента, региональная платформа, CDN | Вход в аккаунт, матч, игровой ping, голос и Vanguard |
| YouTube | Сайт, короткие ссылки, изображения, перенаправление видео | Воспроизведение и скорость видео |

Используются HEAD-запросы по IPv4 / HTTP/1.1 с проверкой TLS, без proxy и автоматических редиректов. Для разных служб заданы допустимые HTTP-коды; 429 и 5xx отображаются как предупреждения сервера. Адреса и правила описаны в [инструкции](docs/USER_GUIDE.ru.md#checks).

Для Discord и YouTube используются исходные группы Flowseal. Для LoL тестер создаёт отдельный адаптированный снимок, сохраняя исходные группы. Команда **Сделать основным** на вкладке LoL запускает именно LoL-вариант. Общая карточка объединяет результаты вариантов и не подтверждает работу всех сервисов через один LoL-вариант.

## Совместимость

- **Windows 11 x64**. Другие платформы не проверены.
- **Flowseal 1.10.2 и 1.10.3**: исследованы 22 стратегии. Для 1.10.3 поддерживается новый формат GameFilter с отдельными диапазонами TCP и UDP.
- Для LoL нужна установленная игра: регион и адреса читаются из её конфигурации. Токены и данные аккаунта не используются.
- Готовый архив содержит .NET. Для сетевых операций нужны права администратора; интерфейс работает без повышения.

Совместимость проверяется по содержимому движка, а не названию папки. У исследованных 1.10.2 и 1.10.3 бинарники совпадают; их SHA-256 закреплены в `isolation-certificate.json`. Другой движок требует отдельной проверки. Неизвестные BAT-конструкции отклоняются. Поддержка всех будущих версий Zapret не обещается.

Подробнее: [проверка 1.10.3](docs/COMPATIBILITY-1.10.3.md) и [статус приёмки](IMPLEMENTATION_STATUS.md).

## Основная стратегия и сохранность данных

При переходе под управление тестера сохраняются конфигурация и состояние существующей службы `zapret`; служба останавливается, её автозапуск отключается. При ошибке перехода предусмотрен откат. Команда **Восстановить Flowseal** возвращает исходную конфигурацию службы; **Остановить основной** только останавливает управляемый процесс.

По умолчанию основной Zapret продолжает работать после закрытия окна. После перезагрузки откройте приложение снова: собственный автозапуск оно не создаёт. Автоматического выбора стратегии нет.

Исходные BAT, списки Flowseal и файлы Riot не изменяются. BAT и `service.bat` не исполняются. Снимки создаются отдельно. Каждый тестовый процесс получает собственные порты; основной процесс исключает тестовый пул. При появлении постороннего обработчика WinDivert или потере наблюдения серия прекращается, её новые результаты становятся недостоверными.

Настройки и результаты находятся в `%LOCALAPPDATA%\ZapretTester`, защищённые снимки и данные восстановления — в `%PROGRAMDATA%\ZapretTester\<SID>`. Изменение профилей, ресурсов или целей делает прежние результаты устаревшими.

## Настройки по умолчанию

| Настройка | Значение |
|---|---|
| Параллельные тестовые процессы | 4; в интерфейсе доступны 1–5 |
| Одновременные запросы на процесс | До 2 |
| Попытки на endpoint | До 2; успешная не повторяется |
| Тайм-аут попытки | 5 секунд, включая DNS |
| Пул локальных портов | 41000–41999 |
| Автопроверка | Выключена |
| Основной процесс после закрытия окна | Продолжает работать |

Discord и YouTube одной стратегии разделяют процесс; LoL использует отдельный вариант. Для 22 стратегий и трёх сервисов это до 44 запусков и бюджет 528 неповторяющихся портов. Увеличение параллельности может ускорить серию, но оптимальное значение зависит от компьютера и сети.

## Если возникла ошибка

Проверьте, что архив распакован полностью, выбрана папка Flowseal целиком и разрешён запуск Helper. Подробности доступны на вкладке сервиса в **Диагностике**, **Журнале** и подсказках индикаторов.

Для обращения создайте [Issue](https://github.com/mwell8/ZapretTester/issues) с версией Windows, Flowseal и тестера, сервисом/регионом, шагами и текстом ошибки. Не прикладывайте `session.json`, токены и полную папку пользовательских данных. Разбор типичных ошибок — в [инструкции](docs/USER_GUIDE.ru.md#troubleshooting).

## Сборка из исходников

Нужны Windows x64, Git, PowerShell 7 и SDK .NET 10.0.301 либо совместимый patch согласно `global.json`.

```powershell
git clone https://github.com/mwell8/ZapretTester.git
cd ZapretTester
dotnet build ZapretTester.sln
dotnet test ZapretTester.sln
.\scripts\Publish.ps1
```

Готовая папка: `artifacts\portable\ZapretTester-win-x64`. Для offline restore при наличии кеша передайте `-PackageSource "$env:USERPROFILE\.nuget\packages"` в `Publish.ps1`. Flowseal и WinDivert не включаются в выпуск тестера.

В solution: `Core` (профили, цели, результаты, HTTP), `Windows` (WinDivert, Job Objects, служба), `Helper` (повышенные права, очередь и локальный IPC), `App` (WPF/MVVM), `TestIsolation` и автоматические тесты. Протокол GUI–Helper — 4.

Интеграционные скрипты в `scripts` и `TestIsolation` требуют отдельной установки Flowseal и могут временно управлять службой и сетевыми процессами. Это инструменты разработчика; для обычного использования они не нужны. Не запускайте их одновременно с работающим Helper.
